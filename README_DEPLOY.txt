GitHub Pages deployment

1. Extract this ZIP on your computer.
2. In the root of your GitHub repository, upload the CONTENTS of the extracted folder, not the ZIP itself. Preserve the images/ subfolders.
3. Commit changes, replacing index.html if asked.
4. Settings > Pages: Deploy from branch main, /(root).
5. Keep your existing favicon.png in the repository (this archive does not replace it).

All 36 distinct images/ paths referenced by index.html are included.
